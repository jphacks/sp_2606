## 今回ローカルに実装したこと

- 通常ログインからパスワードを変更するときは、現在のパスワードをSupabase Authで再検証し、同一利用者であることを確認する。
- パスワード再設定メール用のPKCEフローを、登録メールのフローと区別する。
- 再設定メールのコード交換が成功した場合だけ、アカウント・アクセストークンに紐づく10分間の暗号化HttpOnly Cookieを発行する。
- 通常ログイン、セッションの再発行、ログアウト、パスワード変更受付時に上記許可を破棄する。Cookie削除のみで盗まれたコピーの一回限り使用まで保証するものではない。
- 再設定コード確認後は直接再設定画面へ遷移する。
- 画面だけでなく変更APIでも現在パスワードまたは再設定許可を要求する。
