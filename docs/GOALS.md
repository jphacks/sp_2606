# 検索式の目標設定

確認日：2026-10-17。資格・認定106件、技術・学習テーマ136件、計242件。確認した公式情報から初期候補を収録。網羅性は保証しない。

## 決定事項

- 自由記述に代わり、登録済み候補を名前・略称・日本語の別名で検索する。
- 開始月と達成目標月を必須とする。月の差に1を加え、両端を含む期間を表示。2026-10〜2027-01は4か月。同月は1か月。目標月が開始月より前なら保存不可。
- 技術には到達目標レベル1〜4を設定。資格には設定しない。現在の習熟度とは独立。
- レベル：1 基礎理解／2 手順に沿って実践／3 自力で実践／4 設計・改善。現在の習熟度には0 未経験も設ける。CoStep独自の自己申告の目安で、公式の認定レベルではない。
- 目標は最大5件（暫定上限）。設定なしも可。同じ候補の重複は不可。
- 目標・期間・到達レベルは基本プロフィールと同様にログイン済みユーザーへ公開。ブロック・利用停止を優先する。
- 以前の文章はDBに保持するが、設定画面・プロフィールには表示しない。自動的に資格や技術へ変換しない。旧文章は採点しない。

## おすすめ採点（暫定）

現在の学習分野・経験の0〜130点は維持。目標の最良ペア1つを採用する。複数目標の点数を合計しない。

1. 同じ候補ID：20点。異なる候補は期間やレベルが同じでも0点。
2. 同じ候補の学習期間：`10 × 短い期間 / 長い期間` 点。同じ4か月なら10点、4か月と8か月なら5点。
3. 同じ技術の到達レベル：同じなら10点、1段階差は約6.67点、2段階差は約3.33点、3段階差は0点。資格にはこの加点なし。

資格目標の最大加点は30点、技術目標は40点。全体最大170点。期間は月数を比較する。カレンダー上の重なり、残り期間、達成状態はまだ評価しない。期限を過ぎても自動削除・達成判定はしない。

## データ管理と調査元

原本は `src/data/goal-catalog.json`。各候補に固定ID・種別・カテゴリ・名称・別名・公式URL・確認日・有効フラグを保存。DBの `private.goal_catalog` にも同じデータを収録する。

資格の試験日程・受験料・必要な学習期間・合格保証は収録しない。目標月はユーザー自身の計画。実務経験や前提資格が別途必要な認定もあるため、画面から公式情報を確認できる。

調査元はIPA、AWS、Google Cloud、LPI、LPI-Japan、CNCF、Cisco、ISC2、JDLA、Pythonエンジニア育成推進協会、Rubyアソシエーション、統計検定、および各技術の公式ドキュメント。各項目の出典はJSONの `source_url` を参照。公式本文・画像・教材は転載しない。名称変更時は出典を再確認し、古いIDを別資格へ使い回さない。候補の更新時はUIデータとDBを新しいmigrationで同期する。

## 最終採用の5段階（2026-10-17、008：先行案を置換）
現在・目標とも同じ名称で表示する。
1. 興味・入門：興味があり、これから学びたい・学び始めた段階。
2. 基礎理解：基本的な知識や仕組みを理解している段階。
3. 基本実践：手順や参考資料をもとに、基本的な課題に取り組める段階。
4. 自立・活用：自分で方法を考え、技術を活用して課題を解決できる段階。

## 2026-10-18: 経験・目標・属性
- 技術のプロフィール経験は習熟度のみ、資格は累計時間のみ。日々の学習時間記録は両方継続。
