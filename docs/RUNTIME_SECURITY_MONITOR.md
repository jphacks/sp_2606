# 公開ファイルと認証処理の監視

## 自動化する内容

- **公開ファイル検査**：GitHubのPublic asset securityがmainへのpush時・約30分ごと・手動実行で、公開トップページとそこから発見できる同一オリジンのNext.js静的JavaScriptを取得し、Gitleaks＋CoStep用ルールで秘密情報の候補を検査する。最大100ファイル、1ファイル2MB、合計20MB。リダイレクト、外部サイト、ソースマップは追わない。取得失敗や検査上限も「検査不能」として失敗・通知する。
- **認証監視**：ログインPOST、パスワード再設定メールPOST、MFAのPOST、MFAメール復旧POSTの処理結果を集計する。成功・拒否・サーバーエラー別の1分単位の件数だけ保存。IP・ユーザーID・メール・パスワード・確認コード・トークン・本文は保存しない。
- **定期判定**：Runtime security monitorが約15分ごと・手動実行で直近30分の集計だけ取得し、異常または取得不能なら運営担当ryo7-7へのGitHub Issueを作成する。既存Issueへの追記は約1時間に1回に抑える。通知内容は固定された異常の種類だけで、個人情報や秘密は含まない。

GitHubの定期実行は遅延・停止することがあり、24時間連続監視の保証ではない。メール配送はGitHubのAssignment通知設定に依存する。通知ジョブ自体の失敗もActionsで確認する。

## 初期しきい値（直近30分・全利用者合計）

| 異常 | 判定 |
|---|---|
| ログイン拒否 | 30件以上かつ拒否率70%以上 |
| MFA拒否 | 20件以上 |
| パスワード再設定メール要求 | 成功・拒否・エラー合計15件以上 |
| MFAメール復旧要求 | 送信とコード確認の合計15件以上 |
| 認証関連サーバーエラー | 合計5件以上 |
| 監視取得不能 | 通信・署名取得・DB・設定の異常を安全扱いせず通知 |

少人数の試用向けの暫定値。利用状況に合わせて見直す。正常な再試行やサービス障害でも通知されるため、侵入・漏洩の確定として扱わない。自動停止・自動鍵交換はしない。

## アクセス制御と鍵

- 集計テーブル`private.security_event_counters`はRLS有効、匿名・一般ユーザーの直接アクセスと集計RPC実行は不可。
- Vercelサーバーは既存の`SUPABASE_RECOVERY_SECRET_KEY`を、復旧に加えて監視用の固定RPCにも使用する。名称は復旧用だが実権限は広い管理キーであり、監視専用の最小権限キーではない。GitHubやブラウザへ渡さない。使用箇所を`server-only`モジュールへ限定する。将来別の最小権限DB接続へ分離する余地がある。
- 公開の`/api/security-monitor`はGitHub OIDCの署名、issuer、audience、有効期限、repository/ownerの数値ID、mainブランチ、専用ワークフロー、schedule/手動イベントをすべて確認する。他のPR・リポジトリ・ワークフローは拒否。応答はno-store。
- GitHubには本番のDBキーを追加しない。GitHubが発行する短命のOIDCトークンで、集計値の読み取りだけを許可する。管理者操作や利用者データ取得はできない。
- ローカルとVercel Productionに`SECURITY_METRICS_ENABLED=true`を設定し、SQL0024を適用してから再デプロイする。未設定なら記録を行わず、監視取得は503になる。

## 保存期間・失敗時

DB集計は記録時に7日より前の行を削除する。無操作時は削除が次の記録時まで遅れる。アプリの記録先障害は最大1.5秒で打ち切り、固定の警告ログだけ出し、ログイン自体を監視障害で拒否しない。記録失敗と集計読み取り成功が同時に起きる場合など、全ての記録欠落を自動判定できるものではない。

## 検出できないもの

- 攻撃者がコピーしただけで使用していない鍵、未知の形式の秘密、検査対象に含まれない追加チャンク・認証後ページ・ソースマップ・過去デプロイ。
- Supabase AuthやDBへ直接行われ、CoStepのAPIを通らないアクセス。不正な管理キーの利用、DB管理画面への侵入や内部不正を網羅するものではない。
- サーバーの全ログ・プロセスメモリ・外部サービスでの漏洩。レコード単位での被害調査は、この個人情報を含まない集計だけではできない。

本機能は漏洩・不正利用の一部の兆候を検知する追加対策。漏洩時は`INCIDENT_RESPONSE.md`に従って失効・交換・影響調査する。
