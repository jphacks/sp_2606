# セキュリティ原要件と現行実装の照合

照合日：2026-10-19。コード基準：`6b182fc`。対象：`security/requirements.json` の全74項目と、原典 `docs/security-requirements.md`。

## 判定方法

原文をsource_requirementとして保持し、合意変更はeffective_requirementへ分離。コード・テスト・記録のパスを紐付けた。verifiedは要件の対象範囲を具体的に確認できた項目だけとし、本番の全条件を検証済みという意味ではない。関連テストがあるだけの項目はimplementedに留めた。unverifiedは未実装・運用未整備・証拠不足を含む。詳細は各項目のreasonとverification_scopeを参照する。

Webプッシュは原要件の必須機能なので、未実装を理由に適用除外にしていない。AIレポート8項目のみ、任意機能が現リリースで未採用であるためnot_applicableとした。AIコーディングのレビュー義務はSYS-10として残す。

## 今後の更新

機能追加時はimplementationを、実際に試験したときはtests/evidenceと検証範囲を更新する。未採用機能を有効化する際は適用除外を解除する。verifiedへの変更は原要件全体と適用範囲を確認して行い、証拠ファイルの存在だけで合格にしない。

## 保持期限実装の追記

DEL-04・SYS-13を部分実装として更新。暗号化取得・隔離復元・削除再適用試験等を追加した。verifiedへの変更はない。[確認範囲と制約](BACKUP_AND_RETENTION.md)を参照。冒頭のコード基準と49件の試験記録は初回照合時点の記録。
