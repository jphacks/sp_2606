# CoStep PWAと翌日のセキュリティ確認

## 今回の実装
- Next.js manifest /manifest.webmanifest。CoStep、standalone、起動URL /、スコープ /。
- 192/512pxアイコン、maskable、iPhone用180px。既存ロゴのシンボルを使用。再生成: `node scripts/generate-pwa-icons.mjs`。
- HTTPS本番でのみService Worker登録。開発時のHMRには介入しない。
- ネットワーク接続必須。オフラインでは / の文書遷移だけに、個人情報を含まない503の接続案内を返す。
- Cache Storage、IndexedDB、localStorageへのアプリデータ保存なし。HTML、API、DM、画像、認証、RSC、POSTをオフライン用に保存しない。
- API・認証コールバックはWorkerで処理しない。オンラインHTTPエラーはそのまま返す。オフライン送信のキュー・再送なし。
- 設定にインストール案内。対応ブラウザでは利用者操作でインストールを促す。通知許可を要求しない。
- Webプッシュ通知・アプリ内通知・バックグラウンド同期は未実装。PWA化と通知実装は別。
- SWの更新はHTTPキャッシュを使わず取得。ページを勝手に再読み込みしない。サーバー側は引き続きno-store。OSによるホーム画面用アイコン保持は別。
