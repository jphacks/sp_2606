# タイムライン確認用の架空ユーザー

バッチ：`timeline-demo-20261017-v1`。共有のチーム試用DB向けに明示実行するデータ。自動migration/default seedには含めない。

- 50人、各2投稿（計100件）、各2日分の学習記録。
- 名前は「デモNN」、自己紹介・投稿本文に架空データであることを明記。
- 実在しない予約ドメイン `example.invalid` のメールを使用。パスワード・identityは作成せず、Authのログイン禁止期限も設定。確認メールを送信しない。
- 元のユーザーの設定・投稿・フォロー関係を変更しない。ダミーのUUID衝突があれば全体を中止する。
- 作成ファイル：`supabase/demo/timeline-seed.sql`、データ一覧：`timeline-fixtures.json`。再実行してもユーザー・投稿・学習記録を重複作成しない。
- 削除用SQL：`supabase/demo/timeline-cleanup.sql`。管理用レジストリ・バッチ名・metadata・メールのすべてが一致するダミーだけを削除。今回は削除しない。ダミーに付けたコメント・いいね・会話なども関連ユーザー／投稿の削除により消える。

## 比較方法

現在の学習分野が「Python Lv.1＋Microsoft Azure Lv.1」の場合の期待値。自分の設定が異なれば結果も異なる。

|ダミー|現在の経験|投稿公開範囲|おすすめタブ|
|---|---|---|---|
|デモ01 Python入門|Python Lv.1|全員|表示|
|デモ02 Python基礎|Python Lv.2|全員|表示|
|デモ03 Python発展|Python Lv.5|全員|非表示|
|デモ04 Azure入門|Azure Lv.1|全員|表示|
|デモ05 Azure基礎|Azure Lv.2|全員|表示|
|デモ06 Azure発展|Azure Lv.5|全員|非表示|
|デモ07 PythonとAzure|Python Lv.1／Azure Lv.2|全員|表示|
|デモ08 基本情報入門|基本情報 Lv.1|全員|非表示|
|デモ09 Rust基礎|Rust Lv.2|全員|非表示|
|デモ10 Python時間入力|Python 累計30時間|全員|非表示（入力方法が異なる）|
|デモ11 FF限定Python|Python Lv.1|相互フォロー限定|相互関係なしなら非表示|
|デモ12 非公開Python|Python Lv.1|自分のみ|非表示|

「最新投稿」タイムラインは、新着順の最大20投稿。個人別に点数順で並べ替える機能はまだ実装していない。公開ダミー投稿は96件あり、最大20件のため、直近20件のみ表示される。

「おすすめ」（旧「学習経験が近い」）は同じ分野・同じ入力方法で、レベル差1以内（時間入力なら設定済みの時間差条件）の投稿。上記基準なら5人×2件＝10投稿になる。投稿の文章・目標はこのタブの絞り込みに使わない。

「フォロー中」は承認済みのフォロー先のみ。ダミー追加時に実ユーザーとのフォロー関係を作らないので、追加だけではこのタブには出ない。

ユーザーのおすすめは別機能。登録分野・経験・目標・期間で採点する。デモ12はおすすめ非表示を設定済み。デモ11の基本プロフィールは表示可能だが限定投稿は表示不可。目標の内容・期間の違いもダミーに設定済み。

公式のplaceholder Authユーザー例： https://supabase.com/docs/guides/local-development/cli-workflows#step-4-add-seed-data

## 50人への追加

`timeline-expand-50.sql` は既存12人を変更せず38人を追加する。JavaScript、TypeScript、Java、Go、Ruby、PHP、C系、モバイル、Webフレームワーク、DB、インフラ、クラウド、IPA・AWS・Cisco資格に分散。Goは3人を追加し、同一分野でも異なるレベル・期間を比較できる。追加分は全員が公開投稿・おすすめ対象。全員の分野・目標・レベルは `timeline-fixtures.json` に記載。
